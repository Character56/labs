### Практическое часть

#### Задание 1.

Напишите Sequence-диаграмму отправки ping-запроса на сервер.

**Условия**: В диаграмме должно быть:
- Запрос и ответ от сервера
```mermaid
sequenceDiagram

participant Клиент

participant Сервер

  

Клиент ->> Сервер: ICMP Echo Request (ping)

Note over Сервер: Обработка запроса

Сервер -->> Клиент: ICMP Echo Reply (ответ)

Note over Клиент: Подсчет времени отклика
```
#### Задание 2.

В теоретической части рассматривался пример авторизации на сайте. Напишите подобную sequence-диаграмму авторизации на сайте, но с двойной аутентификацией.

**Условия**: В диаграмме должно быть:
- Ввод пароля
- Двойная аутентификация (например по смс)
```mermaid
sequenceDiagram

participant Пользователь

participant Сайт

participant SMS-шлюз

  

Пользователь ->> Сайт: Ввод логина и пароля

Сайт ->> Сайт: Проверка логина и пароля

  

alt Пароль Верный

    Сайт ->> SMS-шлюз: Запрос на отправку кода

    SMS-шлюз -->> Пользователь: SMS с кодом подтверждения

    Пользователь ->> Сайт: Ввод кода из СМС

    Сайт ->> Сайт: Проверка кода

  

    alt Код верный

        Сайт -->> Пользователь: Успешный вход

    else Код неверный

        Сайт -->> Пользователь: Ошибка: неверный код

    end

else Пароль неверный

    Сайт -->> Пользователь: Ошибка неверный пароль

end
```
#### Задание 3.

Представьте что вы кассир в Пятерочке. К вам приходит покупатель с покупками. Визуализируйте вашу работу с покупателем и кассой.

**Условия**: 
- Должно быть как минимум 4 объекта
```mermaid
sequenceDiagram

participant Покупатель

participant Кассир

participant Сканер

participant Касса

participant Терминал

  

Покупатель ->> Кассир: Передает товары

loop Для каждого товара

    Кассир ->> Сканер: Сканирует штрих-код

    Сканер ->> Касса: Передает данные о товаре

    Касса ->> Касса: Добавляет товар в чек

end

  

Касса -->> Кассир: Итоговая сумма

Кассир ->> Покупатель: Называет сумму

Покупатель ->> Терминал: Оплата картой/наличными

Терминал -->> Кассир: Печать чека

Кассир ->> Покупатель: Выдает чек и товары
```
#### Задание 4*.

Представьте что вы осуществляете DDoS атаку на Сервер. Визуализируйте это в диаграмме.

**Условия**:
- Хакер осуществляет атаку асинхронно.
- Нужно показать как сервер перестаёт отвечать на вопросы
```mermaid
sequenceDiagram

participant Хакер

participant Ботнет1

participant Ботнет2

participant БотнетN

participant Сервер

participant Легитимный клиент

  

Note over Хакер, БотнетN: Асинхроння атака (parallel)

  

par Атака с бота 1

    Ботнет1 ->> Сервер: Флуд-запросы

and Атка с бота 2

    Ботнет2 ->>Сервер: Флуд-запросы

and Атака с бота N

    БотнетN ->> Сервер: Флуд-запросы

end

  

Note over Сервер: Ресурсы сервера исчерпаны

  

Легитимный клиент ->> Сервер: Обычный запрос

Сервер --x Легитимный клиент: Нет ответа (сервер недоступен)

  

Note over Сервер: Сервер перестал отвечать
```
